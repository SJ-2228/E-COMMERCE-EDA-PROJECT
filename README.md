# E-COMMERCE-EDA-PROJECT

E-commerce Sales Analysis Project using Python
This project aims to explore and analyze the performance of an e-commerce business by examining its sales data using Python. The dataset contains detailed transactional records with multiple attributes across orders, customers, products, geography, and profit metrics.
🔍 Key Objectives:
- Understand sales distribution across regions, categories, and time periods
- Identify high-performing products and customer segments
- Analyze profit trends and evaluate discount impact
- Predict sales opportunities and optimize business strategies
📊 Dataset Overview: Each row in the dataset represents a unique transaction and contains:
- Order Details: Row ID, Order ID, Order Date, Ship Date, Ship Mode
- Customer Info: Customer ID, Customer Name, Segment, Country, City, State, Postal Code, Region
- Product Data: Product ID, Category, Sub-Category, Product Name
- Sales Metrics: Sales, Quantity, Discount, Profit
🐍 Tools & Techniques Used:
- Python libraries: Pandas, NumPy, Matplotlib, Seaborn
- Exploratory Data Analysis (EDA)
- Data visualization and correlation mapping
- Profitability insights based on category and customer segment
